# Sago Palm 

**Local Name:** Sago Palm

**Scientific Name:** Cycas revoluta 

**Type:** Tree 

**Location:** Clock Tower

**Habitat:** Ornamental cycad commonly grown in landscaped gardens. Prefers warm climates, sunlight and well-drained soil.
