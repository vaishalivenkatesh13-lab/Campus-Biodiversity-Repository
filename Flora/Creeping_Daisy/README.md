# Creeping Daisy

**Common Name:** Creeping Daisy

**Scientific Name:** Sphagneticola trilobata

**Type:** Herb

**Location:** Clock Tower

**Habitat:** A creeping perennial groundcover commonly found in gardens, open ground, roadsides and other disturbed areas. It grows well in warm, moist, sunny or partly shaded conditions and forms dense mats over the ground.
